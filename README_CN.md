# D4 Bot - Paladin S13 审判连锁爆炸流

## 🚀 快速开始（3步）

### 1. 校准坐标（首次必做，30秒）
```
双击 run_calibrate.bat → 等30秒 → 完成
```
> 需要：D4 运行中，角色站在城镇，HUD 可见

### 2. 捕获技能图标（首次必做，2分钟）
```
双击 run_paladin.bat → 工具箱弹出
F12 → 鼠标移到圣光箭图标 → 截图保存为 01.png
重复: 02=祝福之盾, 03=天堂之矛, 04=圣光光环, 05=天罚
全部放到 assets/skills/paladin/
```

### 3. 开始挂机
```
双击 run_paladin.bat → 选模式 → 开始
END=停止  DEL=暂停
```

---

### 方案 A：直接下载 EXE（推荐）

此仓库每次推送自动构建 `D4Bot.exe`，零依赖，双击即用：
👉 **Actions 标签页 → 最新 run → Artifacts → 下载 D4Bot**

### 方案 B：本地构建 EXE

> 只需运行一次，之后就有独立 EXE

1. 安装 Python 3.9（[python.org](https://python.org)，勾选 Add to PATH）
2. 把整个 `d4-bot` 文件夹拷到游戏本任意位置
3. 双击 `build_exe.bat` → 等待 2-5 分钟
4. 完成后 `dist/D4Bot.exe` 就是成品，拷贝到哪都能跑

## 游戏设置

- 分辨率：**1920×1080 窗口全屏**
- 怪物血条 → **始终显示** / 路径导航 → **开启**

## 技能配置

```
左键: 圣光箭（弹跳3+）
右键: 祝福之盾（引爆+破碎打击）
1键:  天堂之矛（易伤）
2键:  圣光光环（审判仪式）
3键:  天罚（持续上审判）
4键:  审判者誓言（主动引爆）
Q = 药水  Space = 闪避
```

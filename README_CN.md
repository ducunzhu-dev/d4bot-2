# D4 Bot — Diablo 4 自动化辅助

> 🎮 **一键启动，控制面板选职业/模式，傻瓜化操作**

## ⚡ 两种使用方式

### 方案 A：直接运行 EXE（零依赖）
双击 `D4Bot.exe` → 在控制面板选择职业 → 点击"开始挂机"

### 方案 B：Python 源码版
```
双击 run.bat → 控制面板选职业/模式 → 开始
（首次运行会自动安装依赖，约2-5分钟）
```

---

## 🎛️ 控制面板说明

启动后出现悬浮控制面板，所有操作在一个窗口完成：

| 区域 | 功能 |
|------|------|
| **职业选择** | 下拉选择：野蛮人/德鲁伊/灵巫/死灵/法师/盗贼/圣骑士 |
| **模式选择** | Helltide（地狱狂潮）/ Nightmare Dungeon（梦魇地下城）/ Campaign（剧情） |
| **▶ 开始挂机** | 一键启动，bot自动打怪/捡装备/移动 |
| **■ 停止** | 停止bot |
| **🎯 校准** | 首次使用必点！自动识别UI坐标 |
| **🔧 工具箱** | F12截图技能图标，录制/回放路径 |

---

## 🚀 快速上手（3步）

### 1. 校准坐标（首次必做，30秒）
```
启动D4 → 角色站在主城 → 点击控制面板"🎯 校准" → 等30秒 → 完成
```
> 要求：1920×1080 窗口全屏，角色在游戏中（不在菜单/加载界面）

### 2. 截图技能图标（首次必做，2分钟）
```
点击"🔧 工具箱" → 按F12 → 鼠标移到技能图标正中央 → 左键截图
5个技能图标分别存为 01.png ~ 05.png
放到 assets/skills/<职业名>/ 覆盖原文件
```

### 3. 开始挂机
```
选职业 → 选模式 → 点"▶ 开始挂机"
END = 停止   DEL = 暂停
```

## 🗂️ 文件结构

```
D4Bot/
├── D4Bot.exe          ← 独立EXE，双击即用
├── run.bat            ← 统一启动器
├── run_calibrate.bat  ← 命令行校准（备用）
├── build_exe.bat      ← 自行构建EXE
├── config/
│   ├── config.yml                 ← 当前生效配置（界面自动管理）
│   ├── config_s13_barbarian.yml   ← 野蛮人配置
│   ├── config_s13_paladin.yml     ← 圣骑士配置
│   └── config_s13_spiritborn.yml  ← 灵巫配置
├── assets/skills/
│   ├── barbarian/    ← 野蛮人技能图标
│   ├── paladin/      ← 圣骑士技能图标
│   ├── spiritborn/   ← 灵巫技能图标
│   ├── druid/        ← 德鲁伊技能图标
│   └── rogue/        ← 盗贼技能图标
└── 使用教程.md        ← 详细教程
```

## ⌨️ 快捷键

| 按键 | 功能 |
|------|------|
| END | 停止bot |
| DEL | 暂停/恢复 |
| CapsLock | 暂停/恢复 |
| F12 | 截技能图标（需开工具箱） |
| F10 | 获取鼠标坐标（需开工具箱） |
